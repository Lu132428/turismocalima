# Vive Calima El Darién

## Guía turística de Calima El Darién

**Por Diego Cabezas**

Proyecto académico de una guía turística digital para conocer Calima El Darién, Valle del Cauca.

## Páginas

- `Turiscalima.html`: página principal con destinos, actividades, itinerario y actualidad.
- `historia-calima.html`: historia, fundación, símbolos y leyendas de Calima.
- `ayuda-calima.html`: información del sismo, imágenes comunitarias, centros de acopio y contactos de emergencia.

## Archivos principales

- `estilos-calima.css`: estilos visuales de toda la página.
- `calima.js`: funciones básicas de la guía.
- `img/`: fotografías locales de Calima El Darién.

## Cómo abrir el proyecto

Abre `Turiscalima.html` en un navegador. Desde allí puedes acceder a las páginas de historia y ayuda.

## Nota

Las noticias, horarios, centros de acopio y números locales deben confirmarse en sus fuentes oficiales antes de viajar o realizar donaciones.
